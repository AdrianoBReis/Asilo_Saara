# Asilo da Paranoia

Protótipo vertical slice em **Godot 4.7.2**, orientado ao renderizador **Compatibility (OpenGL 3.3)**.

## Como executar

1. Instale Godot 4.7.2.
2. Importe `project.godot` no Project Manager.
3. Em **Renderer**, mantenha **Compatibility** selecionado.
4. Execute o projeto (`F6`/`F5`).

## Controles

| Ação | Controle |
| --- | --- |
| Mover | `WASD` |
| Olhar | Mouse |
| Interagir / tomar remédio | `E` |
| Lanterna | `F` |
| Chamar reunião | `R` |
| Confirmar voto | Botão na tela |
| Capturar mouse | Clique na janela |
| Liberar mouse | `Esc` |

## Conteúdo do vertical slice

- Corredor de asilo, dois quartos e enfermaria construídos proceduralmente.
- Exploração FPS, luzes pulsantes e lanterna com bateria.
- Sanidade individual: escuro e isolamento aceleram sua perda; medicação a restaura.
- Efeitos de paranoia: vinheta, ruído, sussurros e distorção de câmera em sanidade crítica.
- Ciclo de reunião, discussão e votação diegética, incluindo isolamento temporário.
- Áudio posicional local e base preparada para o bus de alucinações.

> Este é um vertical slice local. A voz gravada, os bots e o netcode são extensões planejadas, não estão simulados como recursos prontos neste protótipo.
